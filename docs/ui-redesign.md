# 控制台 UI 测试分支

分支：`ui/vben-console`。本分支不替换正式服务，不合并到主分支。

## 第二阶段：真实框架迁移（2026-09-30）

加入 Vue 3、TypeScript、Vite、Pinia、Ant Design Vue，以及官方 Vben 核心布局和菜单组件。
Vben 源码提交固定于 `frontend/vendor/UPSTREAM.json`，MIT 授权保留在 `frontend/vendor/LICENSE`。
不是继续通过 CSS 模拟 Vben，也没有带入官方 Demo 业务。

| 页面 | 状态 |
| --- | --- |
| 后台框架、导航、页签 | Vue + Vben 核心组件 |
| 登录、注册、微信账号、用户管理、个人设置 | Vue 原生 |
| 调用配置、账号运行管理 | Vue 原生 |
| 扫码、代理、授权链接、系统维护 | Vue 原生，沿用既有后端 API |

旧页面 `/`、`/scan` 等保留，新控制台入口为 `/console/`。新控制台不再使用 iframe 兼容层。
HttpOnly 登录会话、后端权限检查、SQLite/MySQL 配置、公开协议接口均保持不变。
公开页面壳不包含账号数据，管理 API 仍需登录和相应角色权限。
代理入口保留选中账号和返回位置，日志自动刷新保留滚动位置并显示空响应错误。

### 构建

```sh
cd frontend
npm ci
npm test
npm run build
cd ..
go test ./...
go vet ./...
```

前端先构建到 `resource/static/console/`，Go 编译会嵌入这些资源。
Docker 增加 Node 构建阶段，Release/Magisk 通过 `scripts/build-console.sh` 接入构建。
运行设备无需 Node。单独执行 `go build` 前必须先构建前端。
已经构建时可设置 `YYB_FRONTEND_PREBUILT=1`，缺少产物仍会报错，不会静默漏包。

## 第一阶段历史记录

## 设计方向

参考 [Vben Admin](https://github.com/vbenjs/vue-vben-admin) 的管理后台组织方式：
浅色导航、紧凑工具栏、可折叠侧栏、页面页签及统一的表单和数据列表。
保留 YYB 的红色主色和现有业务接口。

第一阶段实现是 Vben 风格的界面改造，当时尚未引入 Vben / Vue 框架。
现有扫码、代理、运行管理等原生脚本仍然执行；页签是页面导航，不会让已关闭的页面继续在后台运行。
第二阶段已接入框架、构建链和全部控制台原生页面，当前进度见上文。

## 本分支范围

- 工作台、微信账号、扫码添加、运行管理、代理设置、用户管理、短链接、个人设置、系统维护使用共同的界面规则。
- 账号列表改为可滚动行列表，支持备注、昵称、ID 搜索及状态筛选。
- 失效账号保留清晰状态，不使用闪烁、灰化或印章动画。
- 登录、注册页面使用统一的简洁表单。
- 新增用户改为页面内表单，密码重置仍使用独立确认对话框。
- 修复普通用户的管理员导航被登录状态判断重新显示的问题，后端权限检查保持不变。
- 导航折叠设置在本浏览器保存；页面页签只在当前标签页会话保存。

## 验证

Go 回归：`go test ./...`。

浏览器测试：先启动隔离的 YYB 测试实例，再执行 `tests/console-ui.cjs`。
该测试使用真实本地登录接口，业务数据与外部服务使用测试响应，不会访问真实微信账号或操作生产任务。
测试需要 Playwright 或 playwright-core、Chromium / Edge，并通过环境变量指定测试地址与凭据。

浏览器测试参数：

| 变量 | 作用 |
| --- | --- |
| `YYB_UI_TEST_URL` | 隔离测试实例地址，默认 `http://127.0.0.1:18016`，只接受本机地址 |
| `YYB_UI_TEST_USER` / `YYB_UI_TEST_PASSWORD` | 隔离测试实例的管理员凭据 |
| `YYB_PLAYWRIGHT` | Playwright 模块名称或本地模块绝对路径 |
| `YYB_BROWSER_PATH` | Chromium / Edge 可执行文件路径 |
| `YYB_UI_TEST_OUTPUT` | 截图与 JSON 测试报告目录 |

测试会在测试实例中创建普通用户，不应对生产数据库运行。
