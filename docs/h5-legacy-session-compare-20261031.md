# 早期会话与近期 H5 实现的真实对照

日期：2026-10-31。关联 [#75](https://github.com/525815266/YYB-Go-Enhanced/issues/75)，以及[未标版本 Docker 的续期观察](unversioned-docker-audit-20261031.md)。

## 结论与范围

同一份早期 YYB 会话在北京时间 16:28 的受限实验中，通过两条独立路径取得了公众号网页授权 code：近期补丁提出的命令1254，以及此前已验证关键流程的 A8Key 5112。两次都得到 32 位 code，回调地址和本次随机 state 严格匹配；穿插的三次小程序取码也全部成功。

这确认早期建立的这份会话能承载新 H5 请求。早期实例缺少 `/wx/oauth` 路由、当前公开版仅生成授权 URL，与微信拒绝这两条真实协议请求是不同情况。本次没有用 H5 成功代替后台续期验收，没有直接宣称补丁原样可合入，也没有验证全部公众号或目标业务登录态。

| 实现 | 本次处理 |
| --- | --- |
| 7 月 31 日原始 Docker 源码 | 保持原服务、后台定时器与数据库；单独读取已建立的会话快照 |

| A8Key 候选 | 重用此前已验证的命令5112、独立 ILink 路径和高编号字段编码；继续微信授权页确认流程 |

公开仓库 `JustF1ne01/yyb` 的 `app/codebridge.py` 最新相关提交仍为 `46ac5a832d5c04ae12727734b4ff08c6a9a72a57`，没有查到晚于前次评审的新提交。本次测试的是经过必要校验修正的1254候选，并非原样运行其中固定 UIN / 设备值的写法。没有改用其凭据恢复或直连兜底逻辑。

## 实际请求结果

目标为此前本人 HAR 和 A8Key 实验已使用的公众号场景；授权范围为 `snsapi_userinfo`，回调为 `https://www.findstars.cn/login`。两种请求分别生成随机 state，各自只构造一次并贯穿回调检查。

| 北京时间 | 步骤 | 结果 |
| --- | --- | --- |
| 16:28:07.591 | 原会话小程序取码对照 | 成功，32 位 code |
| 16:28:08.042 | 命令1254 / oauth_authorize | 传输成功，明确业务 `ret=0`，32 位 H5 code，回调与 state 匹配 |
| 16:28:08.371 | 相同原会话小程序取码 | 成功，32 位 code |
| 16:28:09.693 | A8Key 5112 / 网页确认 | 业务 `ret=0`，授权页 HTTP 200，确认后 HTTP 301；32 位 H5 code，回调与 state 匹配 |
| 16:28:10.120 | 相同原会话小程序取码 | 成功，32 位 code |

实验前后，身份、主凭据、登录票据和数据库中的协议会话均未改变；程序未写数据库、未刷新 OAuth、未建立新握手。原始响应、授权页及一次性 code 均仅保存在私有实验目录，没有访问回调地址或兑换业务 token。

本轮旧版续期样本因此有了额外业务请求，记录为显式实验干预，后续不能称为完全无干预的自然观察。保存的数据不变也不能保证服务端状态完全无影响；本次三次对照只证明对应时刻的调用仍成功。

## 工具与验证

带 `issue75probe` 构建标签的审计文件为 `internal/protocol/h5_compare_audit_test.go` 和 `h5_a8key_compare_helpers_test.go`。默认不参与普通构建；真实用例要求显式私有输入，默认跳过。它不调用通用账号恢复包装器，目标业务失败不会在本工具中删除共享缓存或触发主凭据刷新。

离线用例覆盖原 A8Key 字节向量、缺失 / 非零业务状态、截断 protobuf、回调域名 / 路径 / 固定 query 不匹配、缺 code、错误或重复 state、额外 fragment。相关用例通过，Linux amd64 审计程序已真实运行上述对照。

```text
go test -tags issue75probe ./internal/protocol -run 'TestH5Compare|TestIssue75A8KeyOfflineVector'
```

1254 在本场景下直接返回匹配回调，可作为后续正式接入的优先候选；A8Key 可作独立兼容路径，不能对所有业务拒绝自动切换并重复授权。正式 HTTP 的默认 URL 模式、显式自动授权模式、账号并发和授权变更保护仍需完整接入；当前 `/wx/oauth` 的正式行为仍是生成链接。本次交付的是可复现的隔离对照，不是已发布的用户功能。
