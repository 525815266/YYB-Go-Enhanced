- 保留 YYB Go 多账号登录、签到、代理和通知配置。
- 普通宝箱先查状态再领，读取当天次数、上限、下次可领时间。冷却、封顶、业务失败或进度不增加时停止，不把空响应当作冷却。
- `canContinue` 属于宝箱视频选项，不再用它判断普通宝箱是否可领。
- 独立显示上方免费骑车视频的活动周期进度、下方奖励金视频的当天阶段，以及原普通宝箱的附带视频次数。三个入口不混用上限。
- 查询任务列表：只对服务端已经是 `FINISHED` 的任务调用 `mars.offer.receiveAward`，每次领取后复查任务和余额。`INIT` / `RUNNING` 仅显示状态，不伪造访问首页、询价、发单或设置路线。
- 显示开始余额、结束余额与净变化；回调成功不等于金币到账。

## 配置

- `HELLO_BOX_WAIT_SECONDS`：普通宝箱本轮最多等待秒数，默认 0，最大 60。长时间冷却交给青龙下次调度，不阻塞其他账号。
- `HELLO_CITY_CODE`：可选，城市区号。未设置时保留原宝箱配置，新福利查询不编造定位。
- `HELLO_TASK_MAX_ROUNDS`：普通任务领奖循环安全上限，默认 20，硬上限 50。
- `HELLO_ACCOUNT_LIMIT`：临时验证时限制账号数；未设置或为 0 处理全部账号。
- 原有 `YYB_SERVER`、`YYB_ACCOUNT_NAMES` 等变量继续生效。

未更改现有青龙调度频率。如果每天只执行一次，只会领取当次可领的普通宝箱，不会自动达到 72 次。
