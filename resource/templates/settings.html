维护个人资料、登录密码和设备会话。

扫码渠道

个人设置优先。更新账号时也可切换，确认后替换原 ID 的授权。

协议熔断总控

连续被拒绝或返回空 code 时，暂缓重复请求。总控关闭后所有账号均不熔断；开启时按各账号的设置执行。账号开关在首页「调用配置」中。

保存后下次请求生效并保留到重启之后，清除已有熔断计数。独立限速、黑名单和授权失效处理不受此开关影响。

运行参数

取码限速、登录预算与动态黑名单，保存后 1 秒内生效并保留到重启之后。其余 env 配置见 docs/configuration.md。

取码黑白名单

拒绝的 AppID 不发往上游；白名单优先级最高。内置项与 env 配置只读，面板名单保存到数据库。
